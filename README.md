# Re-Fabrica Front-end MVP

Re-Fabrica هو واجهة MVP عربية بالكامل لمنصة رقمية لإعادة استخدام مخلفات الأقمشة داخل قطاع الملابس والنسيج.

## التشغيل

### Windows (بدون VS Code)
1. افتح مجلد المشروع.
2. انقر نقرًا مزدوجًا على الملف التالي:
   - `start.bat`
3. ستفتح المتصفح تلقائيًا على:
   - http://localhost:8000

### أو من خلال Terminal
```powershell
cd path\to\re-eabrica
npm install
npm start
```

ثم افتح الرابط التالي في المتصفح:
- http://localhost:8000

## ملاحظات
- التطبيق يعمل بالكامل كـ Front-end MVP.
- البيانات تُحفظ داخل `localStorage`.
- جميع الأزرار الأساسية تعمل داخل الواجهة.
- مناسب للعرض كـ مشروع تخرج أو عرض تجريبي.
